# Numerica Lab

Aplicación web estática para explorar métodos numéricos. La interfaz y los cálculos se ejecutan localmente en el navegador.

## Abrir localmente

Abre `index.html` en un navegador moderno. No requiere instalar dependencias ni ejecutar un servidor.

## Publicar con GitHub Pages

1. Crea un repositorio en GitHub y sube el contenido de esta carpeta.
2. En el repositorio, entra a **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama principal (`main`) y la carpeta `/ (root)`, y guarda.
5. GitHub Pages publicará `index.html` como página principal.

## Capítulos incluidos

- Capítulo 1: métodos para ecuaciones no lineales.
- Capítulo 2: sistemas lineales e iteraciones de Jacobi, Gauss-Seidel y SOR.
- Capítulo 3: interpolación y splines, con validación de datos.

## Archivos

- `index.html`: aplicación completa (HTML, CSS y JavaScript).
- `README.md`: estas instrucciones.
